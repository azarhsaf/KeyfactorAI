# Keyfactor AI Assistant

Tool-based, deterministic, offline-capable assistant for Keyfactor Command.

## Confirmed architecture decisions
- MVP API endpoint for data retrieval is `GET /KeyfactorAPI/Certificates`.
- `POST /Certificates/Search` is not used in MVP because your environment returns HTTP 405.
- Backend performs local filtering/counting for expiring/expired cert logic.
- Ollama (`tinyllama:latest`) is optional summarization only.
- Frontend is static build served by frontend nginx, and outer nginx proxies `/api` to backend.

## Environment
Use `.env` values as confirmed:
- `KEYFACTOR_USERNAME=svc_kf_service@irfan.lab`
- `OLLAMA_MODEL=tinyllama:latest`
- `AUTO_PULL_MODEL=false`

## API endpoints
- `GET /api/health`
- `GET /api/keyfactor/diagnostics`
- `GET /api/keyfactor/test-expiring?days=7`
- `POST /api/chat`

## Rebuild/start
```bash
docker compose down
docker compose up -d --build
```

## Behavior guarantees
- No certificate counts are generated by LLM.
- Deterministic tool runs first against Keyfactor API JSON.
- If Ollama fails/missing, response includes deterministic answer plus:
  `AI summary unavailable, but deterministic Keyfactor result is available.`

## Known limitations
- `GET /Certificates` response format can differ by Command version and may need field mapping refinement.
- UI charts are currently placeholders; dashboard cards and diagnostics are implemented.
